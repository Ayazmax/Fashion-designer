# Maison Adeyemi

A colorful couture portfolio for Maison Adeyemi, a fictional fashion house with ateliers in Lagos and Milan. The site is a single static page: campaign imagery, a filterable lookbook, and a fitting request form.

Open `index.html` in a browser, or serve the folder locally:

```bash
python -m http.server 5500
```

The booking form confirms on the page only. It does not send email.
